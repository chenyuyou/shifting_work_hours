# CGE 模型独立实现：可行性分析与技术方案

## 1. 项目背景

当前项目计算了气候变化下中国各省的劳动生产率损失（按工作强度分级），论文中使用 CGE 模型将这些微观生产率损失转化为宏观 GDP 影响（Figure 5）。本文档分析独立实现 CGE 模型的可行性。

## 2. CGE 模型概述

### 2.1 什么是 CGE

CGE（Computable General Equilibrium，可计算一般均衡）模型是一个**多部门、多区域的经济系统模型**，通过求解一组非线性方程组来模拟经济中各部门之间的相互作用。

核心思想：一个部门的冲击（如劳动生产率下降）会通过价格、贸易、要素流动等渠道传导到整个经济系统。

### 2.3 核心方程组

| 方程类型 | 说明 | 数学形式 |
|---------|------|---------|
| **生产函数** | 各部门产出由劳动、资本、中间投入决定 | CES: $Q = A[\delta L^{-\rho} + (1-\delta)K^{-\rho}]^{-1/\rho}$ |
| **需求函数** | 家庭消费由收入和价格决定 | CDE 或 Stone-Geary |
| **贸易方程** | 进出口由国内外价格差决定 | Armington (进口), CET (出口) |
| **市场出清** | 供需均衡条件 | 价格调整使供给 = 需求 |
| **要素市场** | 劳动和资本的供需均衡 | 工资/租金调整 |
| **宏观闭合** | 投资=储蓄，政府收支平衡 | Walras 定律 |

### 4.4 模型流程

```
Step 1: 数据准备
    投入产出表 → SAM 构建 → 部门聚合 → 验证平衡

Step 2: 基期标定
    SAM 数据 → 参数标定 → 基期复制检验（复制基期数据）

Step 3: 情景模拟
    生产率损失（来自 pipeline）→ 作为劳动效率因子冲击
    → CGE 求解 → 新均衡

Step 4: 结果分析
    对比基期 vs 冲击后的 GDP、产出、就业等变化
    → 可视化 → 导出 CSV
```

### 4.5 关键技术决策

| 决策点 | 推荐选择 | 理由 |
|--------|---------|------|
| **求解器** | IPOPT (via Pyomo) | 开源，处理大规模非线性问题效果好 |
| **模型类型** | 单国多区域 | 与论文对应，按省份分区域 |
| **部门分类** | 10-20 个聚合部门 | 降低复杂度，153 部门对 CGE 太大 |
| **生产函数** | CES 嵌套（劳动-资本 → 中间投入） | 行业标准 |
| **贸易** | Armington（进口）+ CET（出口） | 允许国内外产品不完全替代 |
| **宏观闭合** | Johansen 闭合（投资固定） | 简单且常用 |

## 5. 风险与挑战

### 5.1 主要风险

| 风险 | 严重程度 | 应对策略 |
|------|---------|---------|
| **SAM 构建复杂** | 高 | 使用简化版本，参考已有中国 SAM 文献 |
| **弹性参数不确定** | 中 | 敏感性分析，参考 GTAP 数据库 |
| **求解不收敛** | 中 | 调整初始值，使用更好的求解器 |
| **结果难以验证** | 中 | 与论文 Figure 5 对比，与文献对比 |

### 5.2 简化策略

如果完整模型太复杂，可以分阶段实现：

```
Phase 1 (最简版): 2部门模型（农业+非农业），单区域（全国）
    → 验证模型逻辑正确

Phase 2 (标准版): 10部门，3-5区域（东部/中部/西部等）
    → 可以产出有意义的结果

Phase 3 (完整版): 20部门，31省
    → 与论文精度相当
```
