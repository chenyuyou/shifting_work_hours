# CGE 模型实现计划：复现论文结果

## 目标

复现论文 (Lancet Planetary Health 2025) 的 CGE 分析结果，即 Figure 1 和 Figure 2。

## 数据需求

### 1. 中国多区域投入产出表 (MRIO)
- **来源**: CEADs (ceads.net) 或 CMRIO (cmirio.com)
- **内容**: 30 省 × 42 部门的中间使用表、最终使用表、增加值表
- **年份**: 2017 年（论文使用的基准年）
- **格式**: Excel/CSV

### 2. 中国投入产出表 (单区域)
- **来源**: 国家统计局 (data.stats.gov.cn)
- **内容**: 全国 42 部门 IO 表
- **用途**: 构建单区域 SAM 作为验证基准

### 3. 各省 GDP 和就业数据
- **来源**: 中国统计年鉴
- **用途**: 校准各区域 SAM

## 模型规格

### 部门分类（简化版）
根据论文描述，关键部门分为：

| 类别 | 部门 | 特点 |
|------|------|------|
| **室外工作** | 农业、建筑业 | 可调整工时 |
| **室内工作** | 制造业、服务业等 | 不可调整工时 |

简化为 5-8 个聚合部门：
1. 农业 (AGR)
2. 建筑业 (CON)
3. 制造业 (MFG)
4. 能源 (ENE)
5. 服务业 (SER)

### 劳动力分类
- 技术劳动力 (SKL)
- 非技术劳动力 (UNSK)

### 区域划分
- 30 省（论文排除西藏、港澳台）
- 或简化为 6 大区域

### 情景设定
| 情景 | 升温幅度 | 说明 |
|------|---------|------|
| SSP1-2.6 | <2°C | 低排放 |
| SSP2-4.5 | ~3°C | 当前政策 |
| SSP5-8.5 | ~4.5°C | 高排放 |

每个情景有两个变体：
- `_shift`: 调整工时
- `_noshift`: 不调整工时

## 实施阶段

### Phase 1: 数据准备（1-2 周）
1. 下载 2017 年中国 MRIO 表
2. 清洗和标准化数据
3. 构建全国 SAM
4. 构建省级 SAM（30 个）
5. 验证 SAM 平衡

### Phase 2: CGE 模型开发（2-3 周）
1. 扩展现有 2 部门模型为多部门模型
2. 添加劳动力异质性（技术/非技术）
3. 添加 Armington 贸易方程
4. 添加多区域结构
5. 实现递归动态求解器

### Phase 3: 冲击模块（1 周）
1. 编写 pipeline → CGE 的桥接脚本
2. 将生产力损失映射到各部门
3. 实现工时调整的反事实模拟

### Phase 4: 模拟和验证（1-2 周）
1. 运行 3 情景 × 2 变体 = 6 组模拟
2. 产出 GDP 损失时间序列
3. 与论文 Figure 1/2 对比
4. 敏感性分析

## 技术架构

```
src/shifting_work_hours/cge/
├── sam_builder.py        # 从 IO 表构建 SAM
├── mrio_loader.py        # 加载 MRIO 数据
├── model_multi.py        # 多部门多区域 CGE
├── solver_dynamic.py     # 递归动态求解器
├── shock_climate.py      # 气候冲击模块
├── configs/
│   ├── china_2017.json   # 2017 基准配置
│   └── scenarios/        # 情景配置
└── data/
    ├── io_table_2017.csv  # 投入产出表
    └── provincial_sam/    # 省级 SAM
```

## 验证标准

与论文 Figure 1/2 对比：
- 全国 GDP 损失曲线（% GDP，2020-2100）
- 省级 GDP 损失分布
- 调整工时的减排潜力
- 量级应在论文报告的不确定性范围内
